# VeloTracker dependencies (cross-platform)
# Install: pip install -r requirements.txt
#
# Supported platforms:
#   macOS 12+   — Python 3.9-3.13 (any version works)
#   Windows 10+ — Python 3.11 ONLY (see ⚠️ below)
#   Linux       — Python 3.9+ (requires BlueZ + D-Bus)
#
# ⚠️ WINDOWS + PYTHON 3.12+ IS NOT SUPPORTED:
#   bless 0.3.0 (the only stable version on PyPI as of 2026-06) has an internal
#   dependency conflict on Python 3.12+:
#     - bless 0.3.0 requires bleak>=1.1.1
#     - bleak >= 1.0 requires winrt-Windows.Devices.Bluetooth>=3.1
#     - BUT bless 0.3.0 also pins winrt-Windows.Devices.Bluetooth==2.0.0b1
#       (only on Python 3.12+)
#   → pip cannot resolve these together. The conflict is INSIDE bless 0.3.0
#     itself, so we cannot fix it from requirements.txt.
#
#   WORKAROUND: Use Python 3.11 on Windows. With Python 3.11:
#     - bless 0.3.0 uses bleak-winrt (the legacy path) instead of winrt-*
#     - No version pinning conflict
#     - Everything installs cleanly
#
#   To install Python 3.11 on Windows:
#     - Download from https://www.python.org/downloads/release/python-3119/
#     - Or use pyenv-win: pyenv install 3.11.9 && pyenv local 3.11.9
#     - Then: py -3.11 -m venv .venv && .venv\Scripts\activate
#

# === Core (all platforms) ===
opencv-python>=4.8
numpy>=1.24

# bless is pinned to 0.3.x because modules/ble_server.py relies on internals
# (BLEAdapter.__init__ on Windows, BlessServerWinRT.start) that may break on
# a major version bump. Update the monkeypatches before upgrading bless.
#
# On Windows + Python 3.12+, bless 0.3.0 has an unsolvable dependency conflict
# (see note above). Use Python 3.11 on Windows.
bless>=0.3.0,<0.4.0

# === Windows-only (auto-installed by bless on Windows) ===
# pywin32                     — installed automatically
# bleak-winrt>=1.2.0          — installed automatically (Python 3.11)
# winrt-Windows.*==2.0.0b1    — installed automatically (Python 3.12+ ONLY,
#                               but causes conflict — see note above)
#
# MANUAL install required on Windows:
#   pip install git+https://github.com/gwangyi/pysetupdi
#
# === Linux-only (auto-installed by bless on Linux) ===
