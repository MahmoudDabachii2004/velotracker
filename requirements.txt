# VeloTracker dependencies (cross-platform)
# Install: pip install -r requirements.txt
#
# Supported platforms:
#   macOS 12+   - Python 3.9-3.13 (any version works)
#   Windows 10+ - Python 3.11 ONLY (see warning below)
#   Linux       - Python 3.9+ (requires BlueZ + D-Bus)
#
# [WARNING] WINDOWS + PYTHON 3.12+ IS NOT SUPPORTED:
#   bless 0.3.0 (the only stable PyPI release) has an internal dependency
#   conflict on Python 3.12+ Windows:
#     - bless 0.3.0 requires bleak>=1.1.1
#     - bleak >= 1.0 requires winrt-Windows.Devices.Bluetooth>=3.1
#     - BUT bless 0.3.0 also pins winrt-Windows.Devices.Bluetooth==2.0.0b1
#       (only on Python 3.12+)
#   -> pip cannot resolve these together. The conflict is INSIDE bless 0.3.0.
#
#   We tried pinning to bless git master (commit a27e1c25, Apr 2026) which
#   fixes the winrt conflict, but it introduces OTHER breaking API changes
#   (callback signatures, BlessAdvertisementData behavior, registry writes
#   requiring admin) that we couldn't work around cleanly. Reverted to
#   stable bless 0.3.0 + Python 3.11 on Windows.
#
#   WORKAROUND: Use Python 3.11 on Windows.
#   - Download from https://www.python.org/downloads/release/python-3119/
#   - Or use pyenv-win: pyenv install 3.11.9 && pyenv local 3.11.9
#   - Then: py -3.11 -m venv .venv && .venv\Scripts\activate
#

# === Core (all platforms) ===
opencv-python>=4.8
numpy>=1.24

# bless is pinned to 0.3.x (the only stable PyPI release as of 2026-06).
# We tried git master (a27e1c25) but it introduced breaking API changes
# that broke our _read_request/_write_request callbacks and required
# Windows admin for the device name. Reverted to stable 0.3.0.
#
# On Windows, this means Python 3.11 is required (3.12+ has unsolvable
# dependency conflict - see note above).
bless>=0.3.0,<0.4.0

# === Windows-only (auto-installed by bless on Windows) ===
# pywin32                     - installed automatically
# bleak-winrt>=1.2.0          - installed automatically (Python 3.11)
# winrt-Windows.*==2.0.0b1    - installed automatically (Python 3.12+ ONLY,
#                               but causes conflict - see note above)
#
# MANUAL install required on Windows:
#   pip install git+https://github.com/gwangyi/pysetupdi
#
# === Linux-only (auto-installed by bless on Linux) ===
